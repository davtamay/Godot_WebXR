# Native PBR regression workload

The three xbench Godot source files and shared callback timer are copied from the existing local C:/ws/xr/testbed workload used for Claude's November 7 benchmark. They preserve the scene, material definitions and seeded generation. The new project configuration selects Forward+ and the complete current WebGPU bake. This is a separate workload from benchmarks/pbr's canonical shared shader.

Export with tools/export-web-matrix.py, using the godot_webgpu addon from the pinned XR Suite checkout. Copy godot/xbench_timer.js beside each exported index.html. Run `node benchmarks/native-pbr/run.mjs <exports-root> <results-dir>` to check batched/unique rendering in both thread modes. Every browser or engine console error fails; null shaders are not ignored. The screenshots and complete console are retained.

The default 500-object check is correctness coverage, not a performance ranking. Historical shader errors must not be carried forward as a tolerated baseline. Build source and compiler identities belong in the export manifests; retain the original historical logs separately.

`measure.mjs --build <exports-root> --out <new-results> --revision <engine-hash>` rotates Godot single/threaded and pinned PlayCanvas 2.23.3, with three repetitions of 8,000 batched and unique objects. Native engine profilers are disabled by `common_scope=1`; a fresh common observation window records whole renderer-process CPU, callback wall time, and queue-bracketed GPU timestamps separately. Profiling-off CPU controls alternate with profiling-on GPU cases. All timestamp submissions must be accounted for, dependencies must match dependencies.json hashes, and console errors fail immediately. The shared timer is idempotent to avoid Godot's second script request installing another wrapper.

These built-in-material scenes retain different engine batching and shading implementations. They are a throughput comparison at matched scene settings, not pixel-equivalent renderers. Use benchmarks/pbr for the canonical shared-shader image comparison. Native historical gpu_ms and queue-completion wall time must not be mixed with the common timestamp results. Whole-process CPU includes Godot audio and workers; callback CPU does not. No headset performance claim follows from this desktop test.
