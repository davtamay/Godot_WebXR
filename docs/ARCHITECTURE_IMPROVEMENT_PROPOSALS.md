# Architecture Improvement Proposals

This file captures proposed improvements to the baseline spec.

Fable is encouraged to challenge the spec when evidence supports a better approach. Do not silently implement high-risk changes. Capture the proposal here and mark whether it is implemented, pending review, or deferred.

## AIP template

```md
# AIP-NNN: <short title>

## Summary

## Baseline spec says

## New evidence or insight

## Proposed change

## Why this is better

## Cost

## Risks

## Rebase/upstream impact

## Decision needed

## Status
```
